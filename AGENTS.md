# Repository Guidelines

## Code Style and Naming

Follow the style of nearby code. Use four spaces in Python and two spaces in JavaScript. Use `snake_case` for Python modules, functions, and variables; use `camelCase` for JavaScript functions and variables. Name Python tests `test_*.py`.

## Testing Expectations

Add or update tests when behavior changes. Run the relevant tests for the code you changed and report any tests that could not be run.

## Documentation

Write project documentation using ASD-S100, targeting 80% adherence.
