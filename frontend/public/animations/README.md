# Deployed animation clips

These FBX files are served to the browser for avatar gestures. The shared
catalog maps allowed tags to clip filenames.

The source assets are in `TalkingHead/animations/`. Use the documented
[animation sync script](../../../backend/scripts/README.md) to update this
folder, the catalog, and the prompt together. The script removes stale FBX files.

See [speech timing](../../../docs/audio-gesture-synchronization.md).
