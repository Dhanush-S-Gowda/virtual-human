# Deployable avatar models

These GLB files are available to the browser under `/avatars/`. The Docker
frontend build also copies shared models from `TalkingHead/avatars/` into the
production bundle.

Keep avatar settings, model filenames, and licensing consistent when adding a
model. See [TalkingHead](../../../TalkingHead/README.md) and
[frontend settings](../../src/ui/README.md).
