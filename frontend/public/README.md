# Public browser assets

Vite serves these files directly and copies them into the production bundle.
Use stable public URLs for assets loaded at runtime.

- [animations](animations/README.md): gesture FBX clips.
- [avatars](avatars/README.md): deployable avatar models.
- [poses](poses/README.md): pose and dance assets.
- [licenses](licenses/README.md): asset license notices.

`favicon.svg` and `icons.svg` support browser and UI presentation. Files imported
through JavaScript or CSS belong in [src/assets](../src/assets/README.md).
